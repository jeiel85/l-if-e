# v0.3.0 생활 시뮬레이션 검증

검증일: 2026-10-15. Windows, Node.js 24, Chromium / agent-browser.

## 자동 검증

기존 10개 테스트와 새 생활 엔진 5개 테스트를 모두 통과했다. 이전 방식의 전체 729개 조합 검증도 유지했다.

- 같은 시간에 다른 행동을 하면 생활비·초고·사건이 달라진다.
- 자원·경험이 부족한 행동과 사건 선택을 UI뿐 아니라 엔진에서도 거부한다.
- 해결하지 않은 사건을 일상 행동으로 건너뛸 수 없다.
- 16개 시드 × 350단계, 총 5,600번의 행동·결정에서 수치 범위·시간·누적 히스토리를 검사했다. 모든 사건에 선택 가능한 대안이 있고, 무료 회복 경로가 있어 막히지 않는다.
- 실제 행동 규칙으로 완성작·초청·경험·관계를 쌓아 목표에 도달할 수 있다.
- 목표에서 기록을 택하면 마무리되고, 계속 살기를 택하면 같은 목표 질문을 다시 띄우지 않는다.
- 잘못된 수치·이벤트·작업 수·저장 구조를 거부한다.

장기 검증에서 자원 부족과 사건의 대기 시간이 겹쳐 작품 완성의 모든 선택이 닫히는 경로를 발견했다. 사건 선택 가능성 검사와 무료 회복 경로로 수정했다. 관련 이슈: #4.

## 브라우저 검증

- 처음 진입 시 다섯 생활 행동과 네 수치, 비어 있는 히스토리를 확인했다.
- ‘만들기’ 이후 사건 팝업이 자동으로 열리고, 행동이 히스토리에 추가되는 것을 확인했다.
- 선택을 해결하면 같은 주에 결정과 실제 수치 변화가 히스토리에 덧붙는다.
- 생활 공간과 히스토리 컨테이너의 DOM 객체가 행동 전후 같은 객체임을 확인했다. 화면을 통째로 교체하지 않는다.
- 생활 조건에 맞춰 진행해 23주째 완성작 3편·국제 초청 2회·목표 수치를 달성했고, 35개 기록과 목표 질문 팝업을 확인했다. 이 숫자는 해당 경로의 결과이며 고정된 종료 조건의 횟수가 아니다.
- 계속 살기를 선택한 뒤 다음 주 진행을 확인했다. 목표 질문이 반복되지 않았다.
- 새로고침 후 현재 주·수치·히스토리가 복원됐다.
- ‘선택만’ 필터는 행동을 숨기고 결정을 표시하며 원래 기록은 지우지 않는다.
- 목표 이후 기록하기로 마무리하고 기록 화면에서 38개 항목과 최종 수치를 확인했다. 클립보드 차단 시 전체 텍스트와 저작자 표시를 제공했다.
- 이전 버전 형식의 진행·완료 데이터를 준비해 `legacy.html`의 완료 기록을 확인했다. 새 생활 저장 데이터도 함께 유지됐다.

## 모바일과 접근성

390×844 뷰포트에서 문서 너비 390px로 가로 넘침이 없었다. 공책 대화상자 너비·스크롤 너비는 모두 356px였다. 모바일에서도 사건을 Escape로 닫으면 상태가 보존되고, 사건이 대기하는 동안 생활 행동이 비활성화되는 것을 확인했다. 대기 사건을 다시 열어 선택할 수 있었다.

모바일 생활 화면과 목표 팝업의 axe-core 자동 검사에서 위반 0건을 확인했다. 배경 위 일부 문구의 대비는 자동 판정이 불완전하므로 육안으로 별도 확인했다. 히스토리는 로그 영역 안의 순서 목록으로 제공하고, 숫자 키는 입력창·대화상자 안에서 생활 행동을 실행하지 않는다.

실제 모바일 기기·Safari·Firefox·스크린 리더 청취 검증은 하지 않았다. 장기 플레이의 DOM·저장 크기 증가 성능은 하드닝 후보 #5로 남겼다.
